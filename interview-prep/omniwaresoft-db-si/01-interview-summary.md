# 面試整理：角色、條件、怎麼對齊

## 職缺本質

不是 ETL pipeline 開發，而是 **資料庫導入／維運（DB SI）**：

```
合約進來
  → 決定誰架環境（客戶自架 / 你們去架）
  → 安裝、設定、上線
  → 交維運（MA）
  → 定期 health check
  → 版本升級／系統更新再進場
  → 出差到客戶現場
```

老闆在乎：**態度、ownership、teamwork**（現場要把事收完）。

## 兩條產品線

| 路線 | 產品 | 角色感 |
|------|------|--------|
| **SQL（主推你）** | EDB、Greenplum、WarehousePG | DBA／資料庫顧問 |
| **NoSQL** | ELK、Docker、MongoDB | 搜尋／日誌平台＋容器部署 |

面試官叫你去了解 **EDB** → 很大機率希望你走 **SQL 線**。

## 客戶類型（面試提到）

- **製造**：台積電、聯發科這類 → 穩定、分析、log／監控
- **金融**：玉山銀行這類 → 高可用、資安、稽核、可能從 Oracle 遷移

## 薪資（面試口述）

| 項目 | 數字 |
|------|------|
| 月薪 | 42,000 |
| 保證年薪 | 14 個月 → 約 **588,000／年** |
| Bonus | 表現另算（不保證） |
| 第 3 個月考核 | 表現好可加約 **10% 月薪** → 約 46,200 |

試用後若加到 10%、後面仍算 14 薪（粗算）：`42k×3 + 46.2k×11 ≈ 634k`（實際以合約為準）。

## 老闆三件事 → 怎麼講

| 他要的 | 怎麼展現 |
|--------|----------|
| 態度 | 願學產品、願出差、文件讀得完 |
| Ownership | 從架設跟到 health check，不丟半截 |
| Teamwork | 跟客戶 IT／同事／合作方一起收尾 |

可講：

> 我理解這份工作是依合約把資料庫環境建起來、上線、再做 MA 與定期檢查；我願意把一件事從部署跟到維運，也願意配合出差與客戶現場節奏。

## 跟原本 ETL 準備的關係

| 已有 | 用不用得上 |
|------|------------|
| Linux／Docker／架服務 | **直接用** |
| PostgreSQL | **對 EDB／WarehousePG 很有幫助** |
| Elasticsearch | 對 ELK 線有幫助（副線） |
| Pentaho／ETL | 較少當主業，懂資料流仍加分 |
| 出差／導入心態 | **核心** |

2. 出差頻率能不能接受？
3. 42k＋14 薪＋三個月看表現，接不接？若期待更高，問考核標準與是否書面。
